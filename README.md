# trabajo-nuevo-series

Documentación de trabajo de **El Taller del Tío Gallín**, serie vertical para TikTok de la marca Bangover, ambientada en la costa de Ecuador.

- **Temporada 1:** Puerto Candela, pueblo ficticio de la provincia del Guayas.
- **Temporada 2:** Guayaquil.
- **Tesis:** los hombres no piden ayuda, piden que les revisen el carro.

## Por dónde empezar

| Archivo | Qué contiene |
| --- | --- |
| `LEEME-PRIMERO.md` | Entrada a todo lo demás |
| `00-PROMPT-PARA-EMPEZAR.md` | El mensaje listo para pegar al abrir una sesión de trabajo |
| `01-estado-del-proyecto.md` | Qué está hecho y dónde vive cada cosa |
| `02-herramientas.md` | APIs, scripts y comandos, con sus trampas |
| `03-pendientes.md` | El plan de trabajo, en orden, con costos |
| `04-oficinas-tecnicas.md` | Los equipos de especialistas y qué produjo cada uno |
| `05-habilidades.md` | Todo lo ejecutado y las reglas permanentes |
| `06-tablero-de-control.md` | Los 13 roles del proyecto y su estado |
| `prompts/` | Los siete prompts completos, listos para reusar |

## Nota

Este repositorio guarda **documentación y prompts**, no claves ni material generado. Las credenciales viven fuera del repositorio y nunca se versionan.
