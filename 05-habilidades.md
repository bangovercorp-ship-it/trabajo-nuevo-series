**Cómo se combinan:** el panel de expertos decide qué cuenta la serie; el técnico en diagnóstico decide qué se rompe; las dos oficinas deciden dónde ocurre y cómo funciona; el comité decide cómo se habla; y el acabado de cine decide cómo se ve y se oye. El método de escenarios es el que impide que nada de eso se contradiga de un video a otro.

## Las reglas permanentes del cliente

No son prompts, son órdenes que ya costaron correcciones. Se aplican siempre:

- **Solo lo pedido.** No agregar productos, enlaces, precios, imágenes ni datos que nadie pidió. Generar imágenes solo con orden explícita, porque cuestan.
- **Criticar y mejorar lo aprobado.** Cuando se piden "propuestas", son variantes sobre la última pieza aprobada, nunca diseños nuevos desde cero.
- **Parecerse un poquito no es ser igual.** Cuando se pide que algo se parezca a otra cosa, se toca una sola característica, no se reemplaza la figura.
- **Nada inventado:** ni cifras, ni testimonios, ni promesas médicas, ni normativa de un país que no se verificó.
- **Las claves nunca se escriben en el chat.** Viven en `C:\JUEGOS APP\.secretos\`.
- **La marca es de la empresa**, no de un asesor. Las webs de asesores son otra cosa.

## Herramientas de Claude Code que están instaladas y sirven para lo que viene

Ninguna de estas se ha usado todavía en este proyecto. Se mencionan porque el trabajo que sigue es visual y narrativo:

| Skill | Para qué serviría aquí |
| --- | --- |
| `cinematic-director` | Desglose de escenas, lista de planos, prompts de keyframe y de movimiento, continuidad. Es la más cercana a lo que falta |
| `ai-video-storyboard` | Planificar un video de varias tomas cuando la duración pasa de lo que un clip de IA aguanta |
| `video-shotcraft` | Trabajo fino de plano y montaje |
| `marketing-psychology` | Sesgos y resortes de decisión, si se quiere revisar el gancho de un episodio |
| `diseno-con-gusto` | Para cualquier página o pieza gráfica de la marca, que no se vea genérica |
| `graphify` | Convertir toda la biblia en un grafo consultable, si el material crece mucho |

**Lo que sí se usó del entorno:** el conector de documentos de claude.ai para escribir y editar la biblia, la búsqueda web con fuentes ecuatorianas para la parte cultural, y la memoria del proyecto, que guarda las decisiones entre conversaciones.
